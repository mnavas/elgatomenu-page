🍽️ Guía de instalación

Instala ElGatoMenu en tu computadora

Sin conocimientos técnicos. Sigue estos pasos y tendrás ElGatoMenu funcionando en menos de 10 minutos.

Paso 1 — Requisitos previos

ElGatoMenu necesita Docker para funcionar. El asistente de instalación lo descarga automáticamente si no lo tienes. También necesitas Python 3 para ejecutar el asistente.

A

Instala Docker Desktop para Windows

Ve a docker.com/products/docker-desktop y haz clic en Download for Windows.

Ejecuta el instalador. Acepta la configuración predeterminada. Si pide activar WSL 2, acepta — Docker lo necesita en Windows. Reinicia si se requiere. Luego abre Docker Desktop desde el menú Inicio y espera que el ícono de la ballena deje de moverse.

B

Instala Python 3

Ve a python.org/downloads y descarga el instalador más reciente de Python 3.

En la primera pantalla del instalador, marca "Add Python to PATH" antes de hacer clic en Instalar. Esto es importante.

Verifica abriendo una nueva Símbolo del sistema y ejecutando:

python --version

Deberías ver algo como Python 3.12.x.

C

Abre la terminal

Presiona Windows + R, escribe cmd y presiona Enter. O busca PowerShell en el menú Inicio. Usarás esta terminal para los siguientes pasos.

A

Instala Docker Desktop para Mac

Ve a docker.com/products/docker-desktop y haz clic en Download for Mac.

Elige Mac with Apple chip para M1/M2/M3/M4, o Mac with Intel chip para Macs más antiguos. Verifica en Menú Apple → Acerca de esta Mac si no estás seguro.

Abre el .dmg, arrastra Docker a Aplicaciones y ábrelo. Espera que el ícono de la ballena en la barra de menús deje de moverse.

B

Verifica Python 3

Python 3 viene preinstalado en macOS moderno. Abre Terminal (presiona Command + Espacio, escribe Terminal) y ejecuta:

python3 --version

Si ves Python 3.x.x estás listo. Si no, descárgalo de python.org/downloads.

A

Instala Docker Engine

Abre la terminal y ejecuta el instalador oficial de una línea:

curl -fsSL https://get.docker.com | sh

Luego agrega tu usuario al grupo docker para no necesitar sudo:

sudo usermod -aG docker $USER

Cierra sesión y vuelve a entrar para que el cambio tenga efecto.

B

Verifica Python 3

Python 3 viene preinstalado en la mayoría de distribuciones Linux. Verifica con:

python3 --version

Si falta, instálalo:

# Ubuntu / Debian
sudo apt install python3

# Fedora / RHEL
sudo dnf install python3

Paso 2 — Descarga ElGatoMenu

Descarga los archivos de ElGatoMenu a tu computadora. Puedes usar Git o descargar el ZIP.

1

Opción A — Descargar con Git (recomendado)

En la terminal, navega a la carpeta donde quieres instalar ElGatoMenu:

# Windows
cd %USERPROFILE%\Documents

# Mac / Linux
cd ~/Documents

Luego descarga ElGatoMenu:

git clone https://github.com/mnavas/elgatomenu.git
cd elgatomenu
ℹ️ Con Git también puedes actualizar ElGatoMenu fácilmente después con ./elgatomenu update.
2

Opción B — Descargar como ZIP

Ve a github.com/mnavas/elgatomenu, haz clic en el botón verde Code y luego en Download ZIP.

Extrae el ZIP en tu carpeta de Documentos. Tendrás una carpeta llamada elgatomenu-main — abre la terminal dentro de esa carpeta.

Paso 3 — Ejecuta el asistente de instalación

Un solo comando configura todo: genera las claves de seguridad, construye el servidor y crea tu cuenta de administrador.

1

Ejecuta el instalador

# Mac / Linux:
./elgatomenu install

# Windows:
elgatomenu install
2

Responde las dos preguntas

Pregunta 1 — URL de la aplicación: El asistente muestra una lista numerada de las IPs de tu computadora. Elige la que corresponde a tu red WiFi del restaurante. Si no estás seguro, elige la primera opción.

Pregunta 2 — Correo y contraseña del administrador: Usa un correo real que recuerdes. La contraseña se pide dos veces (los caracteres están ocultos) para confirmar.

3

Espera el primer inicio

Después de responder, el instalador descarga y construye todo. La primera vez tarda 5–10 minutos según la velocidad de internet — Docker descarga los componentes. Los inicios siguientes son instantáneos.

Cuando termina, verás:

✓ ElGatoMenu started.

  App:       http://192.168.x.x:3000
  Dashboard: http://192.168.x.x:3000/dashboard
  Studio:    http://192.168.x.x:3001

Abre el enlace del Dashboard en tu navegador e inicia sesión con tu correo y contraseña.

🔒 Mantén el archivo .env privado. Contiene tus contraseñas y claves de seguridad. Git lo ignora automáticamente — nunca lo compartas.

Paso 4 — Configura tu restaurante

Ve a ⚙️ en el encabezado del dashboard. Aquí ajustas el nombre, impuestos, métodos de pago y más.

🏪 Nombre y contacto

Nombre del restaurante (requerido), dirección, teléfono y RUC (opcionales). El nombre aparece en la parte superior de la carta del cliente.

💱 Moneda

Selecciona $ (Ecuador/USA), S/ (Perú), Q (Guatemala), € (Europa) o escribe el tuyo (hasta 3 caracteres).

🧾 IVA

Tres opciones: sin IVA, IVA incluido en los precios, o IVA sumado al final. Para Ecuador elige "incluido" e ingresa 15%.

💰 Cargo por servicio

Sin cargo, porcentaje sobre el subtotal, tarifa fija por pedido, o ambos. Una vista previa muestra el resultado exacto para un plato de $10.00.

🔒 Política de pago

Pago anticipado: el cliente paga antes de que cocina empiece. Pago al final: cocina empieza inmediatamente y el cliente paga al terminar.

💳 Métodos de pago

Activa DeUna, Sipi, transferencia bancaria, efectivo y/o tarjeta. Los métodos digitales piden URL de QR o datos de cuenta.

Haz clic en Guardar cambios cuando termines. Los cambios se aplican de inmediato — sin reiniciar.

Paso 5 — Construye tu carta

Haz clic en 🍽️ Carta en el encabezado del dashboard.

1

Crea las categorías primero

Haz clic en + Categoría, escribe el nombre (p. ej. "Entradas") y presiona Enter. Agrega una por cada sección de tu carta:

Entradas · Sopas · Platos fuertes · Mariscos · Postres · Bebidas

2

Agrega platos

Haz clic en + Añadir plato dentro de una categoría. Completa: emoji (opcional), nombre (requerido), precio y descripción (una línea).

Guarda el plato primero, luego haz clic en ✏️ para reabrirlo y agregar una foto.

3

Agrega fotos (opcional pero recomendado)

Las fotos aumentan significativamente los pedidos. Recomendaciones: imágenes cuadradas, con luz natural, menos de 3 MB, en formato JPEG, PNG o WebP.

Edita el plato (✏️) → haz clic en 📷 Subir imagen → elige la foto. Aparece de inmediato en la carta del cliente.

Paso 6 — Crea los códigos QR para las mesas

Los clientes escanean un QR en la mesa para abrir la carta.

1

Encuentra tu URL

Ejecuta ./elgatomenu hostname para ver todas las URLs disponibles, o usa la que el instalador mostró al final de la instalación.

2

Genera el QR

Ve a un generador de QR gratuito (qr-code-generator.com o similar), ingresa tu URL (http://192.168.x.x:3000) y descarga la imagen.

Consejo: Crea un QR diferente por mesa con el número incluido en la URL: http://192.168.x.x:3000?mesa=5. El formulario de pedido pre-llenará el número de mesa automáticamente.

3

Imprime y prueba

Imprime un QR por mesa. Antes de abrir, haz una prueba completa: escanea el QR con tu celular, agrega platos al carrito, coloca un pedido de prueba y verifica que aparezca en el dashboard.

💡 Pide a tu proveedor de internet o router que asigne una IP fija a la computadora del restaurante. Así la URL nunca cambia y los QR impresos siguen funcionando.

Referencia rápida — comandos del día a día

Ejecuta estos comandos desde la carpeta elgatomenu en la terminal. En Windows usa elgatomenu sin el ./.

Comandos del servidor

Instalación inicial./elgatomenu install
Iniciar./elgatomenu start
Detener./elgatomenu stop
Reiniciar./elgatomenu restart
Ver estado./elgatomenu status
Ver logs en vivo./elgatomenu logs
Ver URLs de red./elgatomenu hostname
Hacer backup./elgatomenu backup
Restaurar backup./elgatomenu restore backups/archivo.sql
Actualizar./elgatomenu update
Crear cuenta admin./elgatomenu add-owner
