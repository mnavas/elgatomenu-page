Cómo cargar una carta de ejemplo en ElGatoMenu

Tiempo estimado: 5 minutos · Solo necesitas Python 3

Los scripts de ejemplo de ElGatoMenu son archivos Python que se conectan a tu instalación y cargan una carta completa — categorías y platos — en segundos. Ideal para probar el sistema antes de ingresar tu carta real, o como punto de partida que luego editas desde el dashboard.

Lo que necesitas

  • ElGatoMenu instalado y funcionando en tu computadora o red local (guía de instalación)
  • Python 3 instalado en la computadora desde donde ejecutas el script (puede ser la misma o una diferente a la del servidor)
  • Tu correo y contraseña de administrador de ElGatoMenu
  • El archivo .py descargado desde la página de Ejemplos
ℹ️ Los scripts no modifican la configuración del restaurante (nombre, IVA, métodos de pago). Solo crean categorías y platos. Puedes ejecutarlos sobre una instalación recién configurada.

Paso 1 — Verifica que Python 3 esté instalado

Abre la Símbolo del sistema (busca "cmd" en el menú Inicio) y ejecuta:

python --version

Deberías ver algo como Python 3.12.x. Si ves un error o una versión 2.x, descarga Python 3 desde python.org/downloads y asegúrate de marcar "Add Python to PATH" durante la instalación.

Abre la Terminal y ejecuta:

python3 --version

Si ves Python 3.x.x estás listo. Si no, instálalo con brew install python3 (Mac) o sudo apt install python3 (Ubuntu/Debian).

Paso 2 — Descarga el script

Ve a la página de Ejemplos, elige el tipo de restaurante que más se parezca al tuyo y haz clic en ⬇ Descargar script. Guarda el archivo .py en una carpeta de fácil acceso, por ejemplo en tu Escritorio o en Documentos.

Paso 3 — Abre la terminal en esa carpeta

Navega hasta la carpeta donde guardaste el script en el Explorador de archivos. Haz clic en la barra de direcciones y escribe cmd, luego presiona Enter. Se abrirá la Símbolo del sistema ya posicionada en esa carpeta.

Abre la Terminal y navega con cd:

cd ~/Desktop   # o donde guardaste el script

Paso 4 — Ejecuta el script

El script necesita saber la URL de tu ElGatoMenu. Si lo corres en la misma computadora del servidor, usa http://localhost:3000. Si lo corres desde otra computadora en la misma red, usa la IP del servidor (la misma que aparece en los QR de las mesas).

# Reemplaza la IP con la de tu servidor
set ELGATOMENU_HOST=http://192.168.1.50:3000
python load_chifa.py

O en una sola línea:

# PowerShell
$env:ELGATOMENU_HOST="http://192.168.1.50:3000"; python load_chifa.py
ELGATOMENU_HOST=http://192.168.1.50:3000 python3 load_chifa.py

# O si el servidor está en la misma computadora:
python3 load_chifa.py

¿Y ahora?

Abre ElGatoMenu en tu navegador (http://{tu-ip}:3000) y verás la carta cargada con todas las categorías y platos. Desde el dashboard puedes:

  • Cambiar nombres y precios de cualquier plato con ✏️
  • Agregar fotos a cada plato
  • Renombrar o eliminar categorías
  • Ocultar los platos que no tienes disponibles
💡 ¿Quieres adaptar el script a tu propia carta? Abre el archivo .py con cualquier editor de texto (Notepad, TextEdit, VS Code). La carta está definida como una lista de Python al inicio del archivo — edita los nombres, precios y descripciones según tu menú real.

Errores comunes

«Login fallido — verifica tus credenciales»

El correo o la contraseña no son correctos. Prueba iniciando sesión manualmente en http://{tu-ip}:3000/dashboard/login para confirmarlo.

«HTTP 404» o «Connection refused»

La URL del servidor es incorrecta o ElGatoMenu no está corriendo. Verifica con ./elgatomenu status y asegúrate de que la IP en ELGATOMENU_HOST es la correcta.

«python» no se reconoce (Windows)

Python no está en el PATH. Reinstala Python desde python.org marcando la opción "Add Python to PATH".

El script crea platos duplicados

Si ejecutas el script dos veces, se crean las categorías y platos por duplicado. Elimina las categorías duplicadas desde 🍽️ Carta en el dashboard.
