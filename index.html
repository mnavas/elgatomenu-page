Funciones

Todo lo que necesitas durante el servicio

Desde la carta digital hasta la pantalla de cocina — ElGatoMenu cubre el ciclo completo de un pedido.

Lo que ve el cliente
📋

Carta digital con QR

Cada mesa tiene su QR. El cliente abre la carta en su celular sin instalar nada — solo el navegador. Fotos, descripciones y precios con IVA o sin él.

🔄

Pago anticipado o al final

Elige el modo que va con tu restaurante: el cliente paga antes de que cocina empiece, o al terminar de comer. Cambiable en cualquier momento.

🖼️

Fotos de platos

Sube una foto por plato directamente desde el editor. Las imágenes se guardan en el servidor — sin servicios externos de almacenamiento.

Durante el servicio
⚡

Tiempo real sin recargar

Las órdenes aparecen en el dashboard y en la cocina al instante, vía WebSocket. No es necesario refrescar la página.

📸

Verificación de comprobantes con OCR

El cliente sube el screenshot del pago. El sistema lee el monto y el ID de transacción automáticamente y avisa si algo no coincide.

🚨

Detección de fraude

Detecta comprobantes duplicados por huella de imagen o por ID de transacción repetido. Muestra alerta en el dashboard antes de que apruebes.

🙈

Ocultar platos al instante

¿Se acabó el ceviche? Un toque en el dashboard y desaparece de la carta del cliente de inmediato. Toca de nuevo para restaurarlo.

👨‍🍳

Pantalla de cocina

Opcional. Muestra cada orden verificada en tiempo real — número, mesa, platos y tiempo de espera. El cocinero toca "Listo" cuando termina.

Gestión y configuración
💰

IVA y cargo de servicio configurables

Elige si el IVA está incluido en los precios o se suma al final. Agrega cargo por servicio: porcentaje, tarifa fija o ambos. Vista previa en vivo antes de guardar.

🏷️

Moneda personalizable

Selecciona $, S/, Q, € o escribe tu propio símbolo. Aparece en todos los precios: carta, resumen, dashboard y pantallas de pago.

👥

Gestión de personal

Crea cuentas para cada miembro del equipo y asigna roles: puede editar la carta, verificar pagos o ver la cocina — de forma independiente.

💾

Backups con un comando

Un solo comando guarda toda la base de datos (menú, órdenes, configuración) en un archivo SQL. Restaurar es igual de simple.

Cómo funciona

Un día de servicio con ElGatoMenu

No se requiere conocimiento técnico. Todo desde el navegador.

☀️ Inicio del día

ElGatoMenu arranca solo cuando enciende la computadora. Abra el dashboard en cualquier dispositivo de la red.

📋 Gestión de carta

Agregue platos, cambie precios o suba fotos desde Carta. Los cambios se reflejan en la carta del cliente de inmediato.

📦 Llegan los pedidos

Las órdenes aparecen en el panel en tiempo real. Cada tarjeta muestra los platos, el total y el método de pago.

🔍 Verificación

Para pagos digitales el OCR lee el comprobante automáticamente. Aprueba o rechaza con un clic. El sistema alerta si detecta fraude.

👨‍🍳 Cocina

Al verificar, la orden llega a la pantalla de cocina. El equipo la ve y marca "Listo" cuando está lista para servir.

🌙 Cierre

El panel muestra el total cobrado del día. Ejecute ./elgatomenu backup antes de cerrar.

Instalación

Funcionando en menos de 10 minutos

Sin conocimientos de programación. Solo una computadora, Docker y el asistente de instalación.

1

Descarga ElGatoMenu

Clona el repositorio con Git o descarga el ZIP desde GitHub. Necesitas Docker (el asistente lo instala si no lo tienes) y Python 3.

2

Ejecuta el asistente

Un solo comando. Te pide la IP de tu red WiFi y un correo y contraseña de administrador. El resto lo hace solo: genera claves, construye y arranca todo.

3

Configura tu restaurante

Entra al dashboard, ajusta nombre, IVA, método de cobro y moneda. Agrega categorías y platos. Imprime el QR de cada mesa. ¡Listo para abrir!

# Descarga ElGatoMenu
git clone https://github.com/mnavas/elgatomenu
cd elgatomenu

# Asistente de instalación — Mac / Linux:
./elgatomenu install
# Windows:
elgatomenu install

# Abre el dashboard en tu navegador
http://192.168.x.x:3000/dashboard
Comandos de gestión
./elgatomenu start     · iniciar
./elgatomenu stop      · detener
./elgatomenu restart   · reiniciar
./elgatomenu backup    · hacer backup
./elgatomenu update    · actualizar
./elgatomenu status    · ver estado
Requisitos mínimos
RAM: 4 GB (recomendado 8 GB)
Disco: 20 GB libres
SO: Windows 10, macOS 12 o Ubuntu 20
Red: WiFi (recomendado cable Ethernet)
Sin internet durante el servicio
